## 0. 符号与约定

| 符号 | 含义 |
| --- | --- |
| $v_x, v_y$ | 底盘平移速度（$x$ 向前、$y$ 向左） |
| $\omega_z$ | 底盘自转角速度（逆时针为正） |
| $v_i$ | 第 $i$ 个轮子的线速度（沿其驱动力方向） |
| $a, b$ | 轮子安装位置到中心的纵向 / 横向距离 |
