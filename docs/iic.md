## 1. 配置记录（I2C3 —— IST8310 磁力计）

### 1.1 为什么是 I2C3

C 板上 **IST8310 三轴磁力计挂在 I2C3** 上，和 BMI088 用的 SPI 是两条独立的总线。磁力计属于本作业的**选做**部分（必做部分只用到加速度计和陀螺仪），但配置清单要求把 I²C 也配好，所以这里一并配通、留作姿态解算的备用传感器。

| MCU 引脚 | 片上信号 | 说明 |
| --- | --- | --- |
| PC9 | I2C3_SDA | 数据线（双向） |
| PH7 | I2C3_SCL | 时钟线（主机产生） |

> ⚠️ **这一对的引脚要拿原理图确认**：C 板教程的引脚表写的是 `PA8 = I2C3_SCL`、`PC9 = I2C3_SDA`；但本次配置把 PA8 分给了 `TIM1_CH1`（PWM1 输出），I2C3 改走 PC9/PH7。
> 如果磁力计读不到，先核对这两根线在板上到底接到哪两个脚。必做部分不受影响。

### 1.2 CubeMX 参数与依据

`Connectivity → I2C3`，生成的初始化函数是 `Core/Src/i2c.c` 里的 `MX_I2C3_Init()`，句柄 `hi2c3`。

| 参数 | 配置值 | 为什么是它 |
| --- | --- | --- |
| I2C Mode | I2C | 标准模式（非 SMBus） |
| **I2C Speed Mode** | **Fast Mode** | 400 kHz，磁力计支持，比标准模式（100 kHz）刷得更快 |
| Clock Speed | 400000 | Fast Mode 的速率 |
| Duty Cycle | 2 | Fast Mode 下的占空比选项（Tlow/Thigh = 2） |
| 7-bit 地址 | 由从机决定（IST8310 为 0x0E 左移后 0x1C） | I²C 靠地址选设备，不靠片选 |

硬件层面：I²C 是**开漏输出 + 外部上拉电阻**，两根线默认被上拉到高电平，任何设备拉低都生效（这也是它能做总线仲裁的前提）。

### 1.3 生成的代码在哪里

```
board/Core/Src/i2c.c      MX_I2C3_Init()、HAL_I2C_MspInit()（I2C3 时钟 + PC9/PH7 复用 AF4）
board/Core/Inc/i2c.h      extern I2C_HandleTypeDef hi2c3;
```

`HAL_I2C_MspInit()` 里能看到 `__HAL_RCC_I2C3_CLK_ENABLE()` 和两个引脚的 `GPIO_InitStruct` —— 说明 I2C3 的外设时钟与引脚复用确实被配置了（这部分是 CubeMX 生成的，不是我手写的）。

### 1.4 本作业的用法

必做部分暂不读磁力计；如果要做姿态解算，读流程是：

```
HAL_I2C_Mem_Read(&hi2c3, IST8310_ADDR, REG, I2C_MEMADD_SIZE_8BIT, buf, len, timeout)
```

即"先写寄存器地址，再重复起始条件读数据"（I²C 的复合帧）。

<!-- 提示：起始条件 S（SCL 高时 SDA 由高到低）→ 7 位地址 + 读写位 → ACK → 数据字节 + ACK → ... → 停止条件 P（SCL 高时 SDA 由低到高）；用自己的话把"什么时候 SDA 允许变化"讲清楚 -->

### 2.3 本作业里 I²C 和 SPI 分别用在哪、为什么这么分？
